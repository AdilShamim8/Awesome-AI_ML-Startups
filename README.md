## 🔥 What Is This?

This repository is the **definitive open-source directory** for tracking AI/ML and tech startups worldwide on a monthly basis. Every month (on the 30th), we publish an updated dataset covering:

- **Startup Name** — Official company name
- **About** — What the startup does in a nutshell
- **Description** — Detailed description of the product/service
- **Website Link** — Direct URL to the startup
- **Category** — Industry vertical (AI/ML, SaaS, FinTech, HealthTech, DevTools, etc.)
- **Funding Stage** — Seed, Series A, Series B, etc.
- **Headquarters** — Location (city, country)
- **Source** — Where we found the data (YC, Crunchbase, Forbes, etc.)
- **Date Added** — When the startup was added to our tracker

### Why This Matters

The AI/ML startup landscape moves at breakneck speed. In Q1 2026 alone, **$255.5 billion** was invested in AI startups globally — surpassing the entire 2025 total. Y Combinator's latest W26 batch included 199 companies with 3 AGI labs. Staying on top of this ecosystem requires systematic tracking, which is exactly what this repo provides.

Whether you're a founder looking for competitors, an investor scouting opportunities, a job seeker targeting high-growth companies, or a researcher mapping the AI landscape — this repo is your monthly pulse check.

## 📈 Data Schema

Each startup entry in our dataset follows this schema:

### CSV Format

```csv
id,startup_name,about,description,website,category,funding_stage,funding_amount,headquarters,founded_year,source,date_added
```

### JSON Format

```json
{
  "id": "001",
  "startup_name": "7AI",
  "about": "AI SOC Agents & Agentic Security Platform",
  "description": "7AI deploys autonomous AI agent swarms for security operations, automating alert enrichment, threat investigation, and incident response at Fortune 500 scale.",
  "website": "https://7ai.com",
  "category": "Cybersecurity",
  "funding_stage": "Series A",
  "funding_amount": "$130M",
  "headquarters": "Boston, USA",
  "founded_year": 2024,
  "source": "Forbes AI 50 / YC",
  "date_added": "2026-05-30"
}
```

### Field Descriptions

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Unique identifier (3-digit) |
| `startup_name` | string | Official company name |
| `about` | string | Short tagline (1 line) |
| `description` | string | Detailed description (2-3 sentences) |
| `website` | URL | Direct link to the startup |
| `category` | string | Industry category |
| `funding_stage` | string | Latest known funding stage |
| `funding_amount` | string | Latest known funding amount |
| `headquarters` | string | City, Country |
| `founded_year` | integer | Year the company was founded |
| `source` | string | Data source (YC, Crunchbase, Forbes, etc.) |
| `date_added` | date | When added to this repo (YYYY-MM-DD) |

## 🤝 Contributing

We welcome contributions from everyone! Whether you're adding a new startup, fixing data, or suggesting new categories — every contribution matters.

### Quick Contribution Guide

1. **Fork** this repository
2. **Add** your startup data to the current month's CSV and JSON files
3. **Update** the relevant category file in `/categories/`
4. **Submit** a Pull Request with a clear description

### Contribution Rules

- ✅ Only add **real, verified** startups with working website links
- ✅ Include the **data source** (where you found the startup)
- ✅ Use the **correct schema** (see [Data Schema](#-data-schema))
- ✅ One startup per row/entry — no duplicates
- ❌ No vaporware or stealth startups without public information
- ❌ No affiliate links or referral codes

👉 See [CONTRIBUTING.md](./CONTRIBUTING.md) for detailed guidelines.
